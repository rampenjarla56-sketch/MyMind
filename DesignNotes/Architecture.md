# Architecture
- `index.html` (repo root = GitHub Pages root): single-file app (HTML+CSS+JS), the only source of truth. State in `localStorage` key `mymind.v1`:
  `{ cur, goal, wake, step, alarm, start, log: [{date, slept, onTime}] }` (log date = the morning after; `onTime` = fell asleep within 30 min of that night's target).
- Plan: `targetFor(nightDate) = max(goal, cur - dayIndex*step)` in minutes, with `rel()` mapping times before noon to "after midnight" so 05:30 > 00:30 > 23:00 orders correctly.
- Wind-down: a linear list of steps; breathing uses CSS transform animation, timed by JS.
- Night sky: stars derived from the log (deterministic hash of date → position); moon fills as on-time nights accumulate. Derived, never stored, never resets.
- Sounds: generated in Web Audio (looped brown/filtered noise buffers), gain-ramped to silence over 20 min. No audio files, nothing downloaded.
- Voice body scan: `speechSynthesis`, opt-in per night.
- Wake alarm: only rings if the page is still open (checked on the dark-screen clock tick); dismissing requires typing "UP". The UI says to set a backup alarm — web pages can't reliably alarm from the background, especially on iOS.
- PWA: `manifest.webmanifest` + `sw.js` (network-first for navigations, cache-first otherwise, versioned cache `mymind-vN` — bump N when shipping) + `icons/` (PNGs generated by script, see RESUME).
- Later: split into modules if it outgrows one file, or port to SwiftUI.
